# Contesto del progetto

Questa applicazione è un percorso didattico per imparare le basi del RAG.

## Obiettivo iniziale

Costruire passo passo un'applicazione Python che:

1. legge documenti testuali da una cartella;
2. li prepara e li salva in un database vettoriale;
3. consente di eseguire ricerche semantiche sui documenti.

Per ora non va realizzata un'interfaccia frontend: l'interazione avviene direttamente tramite file e script Python.

## Regole di lavoro

- Implementare solo il minimo indispensabile richiesto per il passo corrente.
- Procedere per incrementi didattici, spiegando brevemente le scelte e mantenendo il codice leggibile.
- Non anticipare funzionalità dei passi successivi e non introdurre astrazioni o dipendenze non necessarie.
- Non assumere framework, provider di embedding o database vettoriale senza una richiesta o una decisione esplicita.
- Mantenere il progetto Python-first e senza frontend finché il contesto non cambia.
- Consultare la skill `.agents/skills/rag-fundamentals/SKILL.md` per le linee guida verticali sul RAG.
- Quando sono possibili più approcci con conseguenze rilevanti, chiedere prima una scelta e indicare come preferibile l'opzione più semplice, pulita e coerente con il progetto.
